# 9. 运行日志记录

日期：2026-05-21

## 目的

特征提取、CUR、子集筛选、模型训练这类长时间任务不要只依赖终端输出。现在统一把日志写到：

```bash
export WORK_DIR=/root/autodl-tmp/data/outputs/full
export LOG_DIR=$WORK_DIR/logs
mkdir -p "$LOG_DIR"
```

默认日志目录是 `/root/autodl-tmp/data/outputs/full/logs`，仍然放在 `/root/autodl-tmp/data` 下，不放进代码目录，避免本地和 AutoDL 同步大文件时混乱。

## 已接入的脚本

### 全流程脚本

`third_party/ScalSelect/mits_tools/run_mits_pipeline_autodl.sh` 已自动记录日志。

运行后会生成类似：

```text
$WORK_DIR/logs/20260521_153000_mits_pipeline_ratio15.log
```

### 特征提取脚本

`third_party/ScalSelect/run_extraction.sh` 已自动记录日志。

运行后会生成类似：

```text
$WORK_DIR/logs/20260521_153000_feature_extract.log
```

### 通用日志包装器

新增：

```bash
scripts/run_with_log.sh
```

任意重要命令都可以这样运行：

```bash
bash scripts/run_with_log.sh <日志名> <命令> <参数...>
```

例子：

```bash
bash scripts/run_with_log.sh feature_1000_test \
  python third_party/ScalSelect/scripts/feature_extract_sft.py \
    --model "$MODEL_PATH" \
    --model-type qwen \
    --dataset "$WORK_DIR/mits_sharegpt.json" \
    --output-dir "$WORK_DIR/features_test_1000" \
    --feature-mode hybrid_meta \
    --max-samples 1000 \
    --sample-batch-size 8 \
    --image-load-workers 8 \
    --qwen-image-max-pixels 294912 \
    --torch-dtype bfloat16 \
    --max-length 2048
```

日志里会记录开始时间、结束时间、退出码和完整命令。

## Swift 训练日志

新增：

```bash
scripts/run_swift_sft_logged.sh
```

默认读取：

```bash
export MODEL_PATH=/root/autodl-tmp/Qwen/Qwen2.5-VL-7B-Instruct
export WORK_DIR=/root/autodl-tmp/data/outputs/full
export RATIO=15
```

默认训练数据：

```text
$WORK_DIR/mits_selected_15_train64_sharegpt.jsonl
```

默认训练输出：

```text
/root/autodl-tmp/data/train_outputs/mits_15_lora
```

运行：

```bash
bash scripts/run_swift_sft_logged.sh
```

批量训练 5/10/15/20/25/30：

```bash
for r in 5 10 15 20 25 30; do
  RATIO=$r bash scripts/run_swift_sft_logged.sh
done
```

日志会生成到：

```text
$WORK_DIR/logs/*_train_swift_ratio15.log
```

## 查看日志

查看最新日志：

```bash
ls -lh "$WORK_DIR/logs"
tail -n 100 "$WORK_DIR/logs/最新日志文件.log"
```

正式实验建议确认日志中包含：

- `MODEL_PATH`
- `WORK_DIR`
- 数据路径
- batch size
- max length
- image max pixels
- LoRA rank / alpha
- 输出目录
- 开始时间、结束时间、退出码
