## 接 SwanLab 的正式训练

先检查 SwanLab：

```bash
python -c "import swanlab; print('swanlab ok')"
```

如果未安装：

```bash
pip install swanlab -U
```

如果使用 SwanLab 云端，先设置 API Key：

```bash
export SWANLAB_API_KEY="你的SwanLab_API_Key"
```

正式训练：

```bash
cd /root/autodl-tmp/MITS

export DATASET_ROOT=/root/autodl-tmp/data/dataset
export MODEL_PATH=/root/autodl-tmp/Qwen/Qwen2.5-VL-7B-Instruct
export WORK_DIR=/root/autodl-tmp/data/outputs/full
export LOG_DIR=$WORK_DIR/logs
export OMP_NUM_THREADS=8

export RATIO=15
export TRAIN_DATASET=$WORK_DIR/mits_selected_15_train32_sharegpt.jsonl
export TRAIN_OUT=/root/autodl-tmp/data/train_outputs/mits_15_lorasculpt_full_swanlab

export LORASCULPT_INTERVAL=300
export LORASCULPT_PRESERVE_RATIO=0.10
export REPORT_TO="tensorboard swanlab"
export ENABLE_SWANLAB=1
export SWANLAB_PROJECT=MITS-Qwen25VL
export SWANLAB_EXP_NAME=mits_15_lorasculpt_train32
export SWANLAB_MODE=cloud
export LOG_NAME=train_lorasculpt_15_full_swanlab

bash scripts/run_swift_sft_lorasculpt_15_logged.sh
```

如果只想本地记录 SwanLab，不上传云端：

```bash
export SWANLAB_MODE=local
```

## Smoke test 命令

如果修改环境后想再确认一次，可以只跑 100 step：

```bash
export MAX_STEPS=100
export TRAIN_OUT=/root/autodl-tmp/data/train_outputs/mits_15_lorasculpt_smoke
export LOG_NAME=train_lorasculpt_15_smoke
bash scripts/run_swift_sft_lorasculpt_15_logged.sh
unset MAX_STEPS
```

## 训练中监控

查看日志：

```bash
tail -f "$WORK_DIR/logs/"*train_lorasculpt_15*.log
```

重点确认：

```text
[MITS LoRASculpt] extra_callbacks registered
[MITS LoRASculpt] sculpted step=300
memory(GiB) 维持在 46G 左右或以下
loss 不出现 nan
```

查看 checkpoint：

```bash
ls -lh "$TRAIN_OUT"
find "$TRAIN_OUT" -maxdepth 2 -type d -name "checkpoint-*"
```

如果训练中断，从最近 checkpoint 恢复时，在命令中增加：

```bash
--resume_from_checkpoint /root/autodl-tmp/data/train_outputs/mits_15_lorasculpt_full_swanlab/具体版本/checkpoint-xxxx
```
